API - Application programming interface
It is a middleware which helps system to communicate.

Google MAP API, payment, chatgpt api


API is like a waiter in the restaurant.


customer -> give order for food .............. client
Waiter -> takes the order to kitchen  ................ API
Kitchen -> prepare the food ................. server
waiter -> brings food back on the table   ............... API
